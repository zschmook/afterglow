# Alarm recordings

These are the five user-selected recordings from [Mixkit's alarm collection](https://mixkit.co/free-sound-effects/alarm/). `sources.json` records their names, download URLs, file sizes, durations, and SHA-256 checksums.

Run `python tools/fetch_alarm_sounds.py` from the project root to install them locally. The app serves the recordings from this directory; playback needs no connection to Mixkit.

The [Mixkit Sound Effects Free License](https://mixkit.co/license/modal/sfxFree/) permits use in end products, but restricts redistribution as standalone assets or with source files. WAV recordings are therefore excluded from Git; do not add them to source distributions. Review the license for your distribution plans.
