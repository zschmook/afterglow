# Christmas weather faces

The Christmas theme selects these 12 animated SVG faces for current weather,
hourly conditions, the five-day forecast, and the Sport watch face.

| Conditions | Artwork |
| --- | --- |
| Clear day | Santa sun with rotating rays |
| Clear night | Santa moon with its sleeping mouse |
| Overcast | Santa cloud with a fluffy beard |
| Partly cloudy day | Red-nosed reindeer cloud |
| Partly cloudy night | Elf cloud in a Christmas scarf |
| Rain | Cloud under a red and gold umbrella |
| Drizzle | Elf cloud with lighter rainfall |
| Daytime showers | Reindeer cloud with rain |
| Nighttime showers | Santa cloud with rain |
| Fog | Gingerbread cloud with icing and a green bow |
| Snow | Snowman cloud with a top hat, scarf, and falling snowflakes |
| Thunderstorms | Evergreen storm cloud with softly glowing Christmas lights |

Rain remains blue water drops, snow remains falling snowflakes, and lightning
stays recognizable. Reduced motion stops all animation and keeps precipitation
and Christmas lights visible. No external artwork requests are needed.

Based on the bundled Meteocons face variants; the original MIT notice is in
`../meteocons/LICENSE`. Regenerate with `python tools/build_christmas_icons.py`
from the repository root. The builder uses the sibling Halloween builder's
XML and snowfall helpers.
