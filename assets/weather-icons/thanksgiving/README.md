# Thanksgiving / Fall weather faces

The Thanksgiving / Fall theme uses these 12 local SVG variants for current
conditions, hourly weather, forecasts, and the Sport watch face. Switching
themes updates the icons immediately without changing weather labels.

| Conditions | Artwork |
| --- | --- |
| Clear day | Turkey sun with a swaying feather fan |
| Clear night | Pilgrim moon with its sleeping mouse |
| Overcast | Pilgrim cloud |
| Partly cloudy day | Scarecrow cloud with a straw hat |
| Partly cloudy night | Cozy cloud with a knit cap and scarf |
| Rain | Cloud under a harvest gold umbrella |
| Drizzle | Knit cap cloud with lighter rainfall |
| Daytime showers | Scarecrow cloud with rain |
| Nighttime showers | Pilgrim cloud with rain |
| Fog | Scarf cloud over fog lines |
| Snow | Bundled-up cloud with snowflakes |
| Thunderstorms | Pumpkin cloud with rain and lightning |

Rain uses blue water drops; candy rain belongs to the Halloween set.
Motion stops for reduced motion, leaving precipitation visible.

Based on the bundled Meteocons face artwork; the original MIT notice is
retained in `../meteocons/LICENSE`. Regenerate from the repository root with
`python tools/build_thanksgiving_icons.py` (uses the sibling Halloween builder's
XML helpers). No image service or external downloads are required.
